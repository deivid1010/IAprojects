# Imágenes del README

Guarda aquí las imágenes que usa el `README.md` de la raíz, con estos nombres:

| Archivo | Qué debe mostrar |
|---|---|
| `bandeja.png` | Bandeja de conversaciones con el detalle abierto (transcripción y panel Resumen/Técnico) |
| `simulador.png` | Simulador de paciente con una conversación |
| `configuracion.png` | Configuración: modelo de IA, base de conocimiento o agenda |
| `arquitectura-local.png` | Diagrama de la arquitectura local (Docker Compose) |
| `arquitectura-AWS-pruebaWekall.png` | Diagrama de la arquitectura en AWS (exportado desde Excalidraw). Ya está en uso. |

Después, en el `README.md` de la raíz, descomenta la línea `![...](docs/images/...)` correspondiente.
